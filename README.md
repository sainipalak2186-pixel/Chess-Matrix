
# Chess Matrix ♟️

Chess Matrix is a modern chess board clone built using pure HTML and CSS.  
Designed with a sleek black-and-white aesthetic, smooth hover effects, and a clean minimalist interface, this project showcases creative frontend styling using CSS Grid.

## ✨ Features
- Pure HTML & CSS
- Modern monochrome design
- Smooth hover animations
- Responsive chess board layout
- Minimal and elegant UI

## 🛠️ Technologies Used
- HTML5
- CSS3

## 📸 Preview
A stylish chess board interface inspired by modern UI design.

## 🚀 Purpose
This project was created to practice:
- CSS Grid
- UI Design
- Hover Effects
- Frontend Layout Structuring
